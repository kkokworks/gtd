# 받은 일함 비우기

1. 상태 `inbox` 인 항목을 오래된 것부터 가져옵니다.
2. 항목마다 SKILL.md 의 "명료화"로 제안을 만듭니다. 설명에 `제안:` 줄이 있으면(사람 없이 모은 항목) 그것을 출발점으로 씁니다.
3. 표로 보여 줍니다: 번호, 원래 제목, 제안, 고친 제목, 상황·날짜·프로젝트.
4. 사용자의 확인을 받습니다. "다 좋아", "3은 버려", "5는 다음 주부터" 같은 답을 그대로 반영합니다. 확인 전에는 아무것도 바꾸지 않습니다.
5. 도구에 맡기기로 확인한 항목은 그 도구 SOURCE.md 의 "맡기기" 칸대로 맡깁니다.
6. 반영한 뒤 받은 일함이 비었는지 확인합니다. 지금 하기로 정한 것은 마지막에 목록으로 보여 줍니다.
